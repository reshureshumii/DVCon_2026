Stage 1 — VEGA Processor Output
Score1 = Detection Confidence x Task Relevance Weight
YOLO detects all objects and assigns confidence scores. Task relevance weights are applied from a predefined priority map (High / Medium / Semantic Fallback / Default). Objects with Score1 < 0.08 are filtered out. The top 2 candidates are forwarded to the FPGA accelerator for Stage 2.
